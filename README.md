# Gia Dụng Thông Minh 3AE - E-Commerce Website Redesign

Hệ thống website thương mại điện tử chuyên ngành Gia Dụng Thông Minh, thiết kế chuẩn hiện đại, tối ưu trải nghiệm người dùng (UX/UI) và tương thích đa thiết bị.

## Demo Trực Tiếp (GitHub Pages)
- **Website Live:** https://duykoolhp1996.github.io/gia-dung-thong-minh-3ae/
- **Studio Preview Hub (So sánh & Đa thiết bị):** https://duykoolhp1996.github.io/gia-dung-thong-minh-3ae/preview.html

## Danh Sách Các Trang
- `index.html`: Trang chủ Desktop tích hợp Quick Cart Drawer
- `chi-tiet-san-pham.html`: Chi tiết sản phẩm Nồi Lẩu Điện Đa Năng Gaabor EC-30T01A
- `gio-hang.html`: Giỏ hàng đầy đủ, voucher giảm giá
- `thanh-toan.html`: Trang thanh toán & đặt hàng đa phương thức
- `da-thanh-toan.html`: Trang xác nhận đơn hàng thành công kèm VietQR
- `dai-tiec-khuyen-mai.html`: Landing Page chiến dịch Đại Tiệc Khuyến Mãi
- `gioi-thieu.html`: Trang Giới thiệu & Triết lý thương hiệu từ dữ liệu chuẩn
- `mobile-trang-chu.html`: Giao diện Trang chủ tối ưu cho thiết bị di động
- `mobile-san-pham.html`: Giao diện Chi tiết sản phẩm Mobile
- `preview.html`: Studio Hub so sánh Live HTML và ảnh chụp Stitch gốc 2560px

## Công Nghệ Sử Dụng
- HTML5 / Responsive Semantics
- Tailwind CSS (CDN Configured)
- Google Fonts: Plus Jakarta Sans
- Google Material Symbols Outlined
- Tracking: Google Analytics 4 (`G-9KQYN3R3X2`) & Hotjar (`hjid: 6791459`)
