# Product Card

Thẻ hiển thị sản phẩm gia dụng thông minh chuẩn e-commerce.

Bao gồm:
- Khung ảnh sản phẩm tỷ lệ vuông 1:1 kèm nhãn giảm giá đỏ và nút yêu thích nhanh.
- Nhãn cam kết chính hãng / hỗ trợ VAT.
- Tên sản phẩm tối đa 2 dòng kèm đánh giá sao.
- Cụm giá bán nổi bật (giá khuyến mãi vàng/đen, giá gốc gạch ngang).
- Nút thêm vào giỏ hàng hoặc mua nhanh.
