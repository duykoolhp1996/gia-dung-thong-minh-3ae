# Header

Thanh điều hướng tiêu chuẩn của thương hiệu Gia Dụng Thông Minh, bao gồm dải thông báo cam kết màu vàng và thanh công cụ màu đen chứa ô tìm kiếm bo tròn pill cùng các lối tắt tác vụ.

## Cấu trúc
1. **Top Announcement Bar (`.gdtm-topbar`)**: Dải màu vàng `#FCD10C` làm nền cho cam kết chính hãng và hỗ trợ xuất VAT.
2. **Main Navigation (`.gdtm-navbar`)**: Nền đen `#000000` tạo độ tương phản cao, chứa logo vàng, danh mục, thanh tìm kiếm thông minh và cụm tài khoản/giỏ hàng.
