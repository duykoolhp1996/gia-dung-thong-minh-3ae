# Button

Hệ thống nút bấm hành động của Gia Dụng Thông Minh.

## Biến thể (Variants)
- **Primary (`gdtm-btn-primary`)**: Nền vàng thương hiệu `#FCD10C`, chữ đen đậm. Dùng cho hành động quan trọng nhất trên màn hình (Mua ngay, Thêm vào giỏ, Xác nhận đơn).
- **Secondary Dark (`gdtm-btn-dark`)**: Nền đen `#000000`, chữ trắng. Dùng cho các hành động phụ thuộc hoặc bộ lọc.
- **Outline (`gdtm-btn-outline`)**: Viền vàng hoặc viền xám, nền trong suốt. Dùng cho Xem chi tiết, So sánh sản phẩm.
- **Soft Gold (`gdtm-btn-soft`)**: Nền vàng nhạt `#FEF9C3`, chữ nâu sẫm/đen.
