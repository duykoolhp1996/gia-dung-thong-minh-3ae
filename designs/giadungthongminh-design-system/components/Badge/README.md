# Badge & Tag

Hệ thống nhãn thông tin và cam kết thương hiệu.

## Biến thể (Variants)
- **Top Announcement Chip (`gdtm-chip-vat`)**: Nền vàng đậm hoặc pill mờ trên nền vàng với dấu chấm tròn cam kết.
- **Genuine Green (`gdtm-badge-success`)**: Nhãn chứng thực chính hãng 100%.
- **Discount Red (`gdtm-badge-danger`)**: Nhãn giảm giá % nổi bật trên góc ảnh sản phẩm.
- **Info Blue (`gdtm-badge-info`)**: Xuất hóa đơn VAT, bảo hành điện tử chính hãng.
- **Brand Gold (`gdtm-badge-brand`)**: Giao nhanh 2h, trả góp 0%.
